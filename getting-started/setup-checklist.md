# Setup checklist

Work through this list after [installing](installation.md) Pipsy. Each step links to the page that explains it.

1. **Logo and favicon.** Upload your logo in **Theme settings > Logo**. Without an upload, the header and footer show the wordmark text from the Header and Footer sections. See [Logo and favicon](../theme-settings/logo-and-favicon.md).
2. **Colors.** Check the eight color schemes in **Theme settings > Colors**. Sections pick a scheme, so changing a scheme changes every band that uses it. See [Colors](../theme-settings/colors.md).
3. **Products.** Give each product a **Colour** option and a **Size** option. Use age sizes written with an en dash, like `2–3Y` or `0–3M`, so Pipsy can show the size range and child heights. See [Size data](../product-page/size-data.md).
4. **Collections.** Create the collections your home page links to (age bands, categories, occasions). Links to collections that do not exist hide themselves. See [How links behave](../reference/links.md).
5. **Menus.** Create a main menu (up to three levels) and up to three footer menus, then pick them in the Header and Footer sections. See [Navigation menus](../header-footer/navigation-menus.md).
6. **Mega menu.** Add a **Mega panel** block to the Header for each top-level item that should open a large panel. See [Header and mega menu](../header-footer/header-and-mega-menu.md).
7. **Content pages.** Create About, Contact, FAQs, Order tracking and Size guide pages and assign the matching `page.*` templates. See [Creating content pages](../content-pages/creating-pages.md).
8. **Size data.** Add `size_range` and `size_chart` metaobjects so the height helper and size guide use your numbers. See [Size data](../product-page/size-data.md).
9. **Reviews (optional).** Install a reviews app and place its block in the Reviews band. See [Product reviews](../product-page/reviews.md).
10. **Filters.** Install Shopify Search & Discovery and choose filters (Availability, Price, Colour, Size). See [Collection page](../shopping/collection-page.md).
11. **Home page.** Replace the demo images, texts, products and collections in each home section. See [Home page overview](../home-page/overview.md).
12. **Policies and social links.** Add store policies (**Settings > Policies**) for the footer legal row and contact form, and social links in **Theme settings > Social media**.
13. **Preview on a phone** with the device toggle in the editor, then [publish](installation.md#publish).

{% hint style="info" %}
Demo text such as "A demo store: products are illustrative and not for sale" in the footer, or "Sample data" labels on the testimonials, are settings. Replace or clear them before you go live.
{% endhint %}
