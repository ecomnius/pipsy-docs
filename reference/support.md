# Support

Pipsy is made by **Novaworks**. To get help, send a request at [novaworks.net/get-support](https://novaworks.net/get-support). We review requests on business days in Vietnam (GMT+7) and reply by email.

## Before you contact support

1. Check [FAQ and troubleshooting](troubleshooting.md).
2. Make sure you run the latest Pipsy version (see [Changelog](changelog.md)).
3. Test with apps turned off in **Customize > App embeds** to rule out an app conflict.

## What to send

* Your store's `myshopify.com` address and the theme name as shown in **Online Store > Themes**.
* A preview link of the theme (**… > Share preview**).
* The page and the steps to see the problem, with a screenshot.
* Whether you changed theme code. Support covers the theme as shipped; custom code changes are not covered.

{% hint style="warning" %}
Never send your admin password or staff login. If someone needs access to your store, add them as a collaborator or staff account in **Settings > Users**.
{% endhint %}

## Updating the theme

Shopify does not overwrite a customised theme. To update, add the new version as a draft (see [Installation](../getting-started/installation.md)), copy your settings across in the editor, preview, then publish.
